Auditoría de seguridad de tu sitio y servidor

Seis verificaciones, una por clase, en una sola ejecución y con informe fechado. Ejecutas la auditoría en el kit, plantas un secreto para ver cómo se detecta la rotura y sales con el plan de revisión: la spec cambia, las dependencias cambian, y la auditoría se ejecuta de nuevo.

Comenzar la clase

En esta clase vas a

  1. 1Las seis verificaciones y de qué clase viene cada una
  2. 2El informe fechado que graba la auditoría
  3. 3Una rotura plantada a propósito y detectada
  4. 4Tu plan con fechas y la próxima revisión

Objetivo: ejecutar la auditoría completa (página, fallback, exposición, catálogo, servidor, secretos), ver cómo se detecta una rotura y salir con el plan fechado.

// auditar.mjs — la auditoría de seguridad de todo el curso en una sola ejecución (lección 8).
// 6 verificaciones, cada una de una lección; guarda relatorio-seguranca.md con fecha y resultado.
//   1 página      checar.mjs: texto de terceros marcado; la acción con consecuencias pide confirmación (lecciones 2–3)
//   2 fallback    la página funciona sin WebMCP (el caso de la mayoría de los visitantes)
//   3 exposição   toda página .html que no es index envía Permissions-Policy con tools=() (lección 4)
//   4 catálogo    ameacas.mjs sin hallazgos (lección 7)
//   5 servidor    atacar-mcp.mjs seguro: 0 de 6 ataques pasan (lección 5)
//   6 segredos    segredos.mjs en la carpeta del kit: 0 secretos (lección 5)
// Uso: node scripts/auditar.mjs     (PAGINA=<carpeta> y CATALOGO=<archivo> para tu copia)
// Salida 0 = 6/6; 1 = alguna falló.
import { spawnSync } from 'node:child_process';
import { readdirSync, writeFileSync } from 'node:fs';
import { resolve } from 'node:path';
import { KIT, pastaPagina, servir, abrir } from '../lib/navegador.mjs';

const node = (...args) => spawnSync(process.execPath, args, { cwd: KIT, encoding: 'utf8', timeout: 240000 });
const ultima = r => (r.stdout || r.stderr || '').trim().split('\n').at(-1);
const res = [];
const anotar = (n, nome, ok, det) => { res.push({ n, nome, ok, det }); console.log(`${ok ? 'ok   ' : 'FALHA'} ${n} ${nome}: ${det}`); };

const pasta = pastaPagina();
const s0 = await abrir('sem');
console.log(`== ${s0.versao.replace(' · modo: sem', '')} · ${new Date().toISOString().slice(0, 10)}`);

let r = node('scripts/checar.mjs');
anotar(1, 'página', r.status === 0, ultima(r));

const fb = await s0.page.evaluate(() => ({ modo: document.documentElement.dataset.webmcp, itens: document.querySelectorAll('li').length }));
anotar(2, 'fallback', fb.modo === 'sem' && fb.itens > 0 && !s0.erros.length, `sem WebMCP: ${fb.itens} itens na tela, ${s0.erros.length} erros de JS`);
await s0.fechar();

const srv = await servir(pasta);
const paginas = readdirSync(pasta).filter(f => f.endsWith('.html') && f !== 'index.html');
const sem = [];
for (const p of paginas) {
  const pp = (await fetch(srv.url + p)).headers.get('permissions-policy') || '';
  if (!/\btools=\(\)/.test(pp)) sem.push(p);
}
await srv.fechar();
anotar(3, 'exposição', sem.length === 0, sem.length ? `sem Permissions-Policy tools=(): ${sem.join(', ')}` : `${paginas.length} página(s) sem ferramenta com tools=()`);

r = node('scripts/ameacas.mjs', process.env.CATALOGO || resolve(pasta, 'ferramentas.mjs'));
anotar(4, 'catálogo', r.status === 0, ultima(r));

r = node('scripts/atacar-mcp.mjs', 'seguro');
anotar(5, 'servidor', r.status === 0, ultima(r));

r = node('scripts/segredos.mjs', '.');
anotar(6, 'segredos', r.status === 0, ultima(r));

const okN = res.filter(x => x.ok).length;
const hoje = new Date().toISOString().slice(0, 10);
writeFileSync(resolve(KIT, 'relatorio-seguranca.md'),
  `# Relatório de segurança — ${hoje}\n\nSpec WebMCP: rascunho CG de 16/10/2026 · MCP 2026-07-28\n\n| # | verificação | resultado | detalhe |\n|---|---|---|---|\n` +
  res.map(x => `| ${x.n} | ${x.nome} | ${x.ok ? 'ok' : 'FALHA'} | ${x.det.replace(/\|/g, '/')} |`).join('\n') +
  `\n\nTotal: ${okN}/6. Rode de novo a cada mudança de ferramenta, de dependência ou da spec.\n`);
console.log(`AUDITORIA: ${okN}/6 ok · relatório: relatorio-seguranca.md`);
process.exit(okN === 6 ? 0 : 1);

03 · Una rotura plantada

Un archivo olvidado con un token dentro de la carpeta de la página. El bloque lo planta, audita y lo borra.

Terminal · rotura
cd ~/projetos/formacao-webmcp-seguranca-v72/kit
printf "export const TOKEN = '%s';\n" $(openssl rand -hex 16) > pagina/config-esquecida.mjs
node scripts/auditar.mjs | tail -2; echo "saída: ${PIPESTATUS[0]}"
rm pagina/config-esquecida.mjs
Ejemplo del repositorio
FALHA 6 segredos: 71 arquivos lidos · 1 segredo
AUDITORIA: 5/6 ok · relatório: relatorio-seguranca.md
saída: 1

Salida 1: puedes usar la auditoría como compuerta antes de publicar (en el CI o en un hook de pre-push).

04 · Auditar tu sitio

1. Página

Una copia local de tu página que registre las tools y marque document.documentElement.dataset.webmcp al final. PAGINA=[carpeta] cambia la carpeta; CANARIO y CONFIRMAR cambian el canario y el selector de tu diálogo.

2. Catálogo

CATALOGO=[archivo] apunta al módulo con las definiciones, si no es ferramentas.mjs.

3. Servidor

El atacar-mcp.mjs ataca el servidor del kit. Para el tuyo, copia los seis ataques y cambia el subir() por la URL de tu servidor de prueba, con tokens de prueba de tu proveedor.

4. Cuándo ejecutarla

Con cada tool nueva, con cada actualización de dependencias y cuando cambie la spec. WebMCP es un borrador: el origin trial llega hasta Chrome 156 y la API ya cambió de nombre una vez.
