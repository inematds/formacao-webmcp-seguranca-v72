Lesson 3 · 18 min

An action with consequences needs a human: confirmation and consequentialHint

Booking, canceling, paying, deleting. The agent may pick the wrong tool, misread the description, or obey planted text. The WebMCP spec answers with consequentialHint, so the client can require confirmation. In this lesson you add the annotation and your site's own confirmation, and you prove that declining changes nothing.

Start the lesson

In this lesson you will

  1. 1Misdescribed intent: the spec's finalizeCart case
  2. 2consequentialHint (a signal for the client) and the site's confirmation (your lock)
  3. 3The test that declines and checks that nothing changed
  4. 4The limit: an agent that operates the screen can click the button too

Goal: add consequentialHint and a confirmation with target and effect to every tool that changes something, and prove that declining changes nothing.

The annotation is for the client; the confirmation is yours. One doesn't replace the other.

02 · Confirmation that protects

1. Target and effect

The question says what, whose, and what happens next. "Are you sure?" won't do: the person doesn't know what they're approving.

2. Tied to the call

One question per call, with that call's arguments. If the target changes, it's a new question. Never a "yes" that covers the next ones.

3. A name that states the effect

The spec shows finalizeCart: the agent thought it was only closing the cart to look, and the tool made the purchase (§6.3.2.3). Name and description state the effect: comprar_carrinho, "charges the saved card".

4. The limit

The dialog lives on the page, and an agent that operates the screen can click Confirm too. checar.mjs itself clicks, the way an agent would. For a high-value action, ask for something the agent doesn't have: the password again, or a code sent to the person.

03 · The second hole: canceling without asking

Edit cancelar_agendamento in kit/pagina/ferramentas.mjs as in the snippet and run the checker. The finished version is in kit/solucao/aula3/.

Snippet · kit/solucao/aula3/ferramentas.mjs
      annotations: { consequentialHint: true },              // lesson 3: warns that the action has consequences
      execute: util(async ({ codigo }, { signal }) => {
        const ag = agenda.agendamentos().find(a => a.codigo === codigo);
        if (!ag) throw new Error(`agendamento não encontrado: ${codigo}`);
        // the question states the target and the effect in full; aborting the run (signal) counts as "no"
        const ok = await ui.pedirConfirmacao(`Cancelar o agendamento ${ag.codigo} (${ag.id}, ${ag.nome})? A vaga volta para a agenda.`, signal);
        if (!ok) return { cancelado: false, motivo: 'a pessoa recusou na tela' };
        agenda.cancelar(codigo);
        ui.atualizar();
        return { cancelado: true, agendamento: ag };
      })
