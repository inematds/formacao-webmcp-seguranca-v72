Aula 3 · 18 min

Ação com consequência pede humano: confirmação e consequentialHint

Reservar, cancelar, pagar, apagar. O agente pode escolher a ferramenta errada, entender mal a descrição ou obedecer a um texto plantado. A spec do WebMCP responde com consequentialHint, para o cliente exigir confirmação. Nesta aula você põe a anotação e a confirmação do próprio site, e prova que recusar não muda nada.

Começar a aula

Nesta aula você vai

  1. 1Intenção mal descrita: o caso finalizeCart da spec
  2. 2consequentialHint (sinal para o cliente) e confirmação do site (a sua trava)
  3. 3O teste que recusa e confere que nada mudou
  4. 4O limite: um agente que opera a tela também clica no botão

Objetivo: pôr consequentialHint e uma confirmação com alvo e efeito em toda ferramenta que muda algo, e provar que recusar não muda nada.

01 · Do pedido ao efeito, com uma pessoa no meio

Clique em cada etapa.

Clique em cada bloco do diagrama para ver o que ele faz.

A anotação é para o cliente; a confirmação é sua. Uma não substitui a outra.

02 · Confirmação que protege

1. Alvo e efeito

A pergunta diz o que, de quem e o que acontece depois. "Tem certeza?" não serve: a pessoa não sabe o que está aprovando.

2. Presa à chamada

Uma pergunta por chamada, com os argumentos daquela chamada. Se o alvo mudar, é outra pergunta. Nunca um "sim" que vale para as próximas.

3. Nome que diz o efeito

A spec mostra finalizeCart: o agente achou que só fechava o carrinho para ver, e a ferramenta comprou (§6.3.2.3). Nome e descrição dizem o efeito: comprar_carrinho, "cobra o cartão salvo".

4. O limite

O diálogo está na página, e um agente que opera a tela também consegue clicar em Confirmar. O próprio checar.mjs clica, como um agente faria. Para ação de alto valor, peça algo que o agente não tem: a senha de novo ou um código enviado à pessoa.

03 · O segundo furo: cancelar sem perguntar

Edite cancelar_agendamento em kit/pagina/ferramentas.mjs como no trecho e rode o checador. A versão pronta está em kit/solucao/aula3/.

Trecho · kit/solucao/aula3/ferramentas.mjs
      annotations: { consequentialHint: true },              // aula 3: avisa que a ação tem consequência
      execute: util(async ({ codigo }, { signal }) => {
        const ag = agenda.agendamentos().find(a => a.codigo === codigo);
        if (!ag) throw new Error(`agendamento não encontrado: ${codigo}`);
        // a pergunta diz o alvo e o efeito por extenso; cancelar a execução (signal) vale como "não"
        const ok = await ui.pedirConfirmacao(`Cancelar o agendamento ${ag.codigo} (${ag.id}, ${ag.nome})? A vaga volta para a agenda.`, signal);
        if (!ok) return { cancelado: false, motivo: 'a pessoa recusou na tela' };
        agenda.cancelar(codigo);
        ui.atualizar();
        return { cancelado: true, agendamento: ag };
      })
